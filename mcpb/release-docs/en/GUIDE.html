SketchUp MCP – Let Claude work directly in SketchUp

Ask Claude in plain language – in any language – to read your model, run quantity takeoffs, model geometry, assign materials and tags, take screenshots and export files, right in the SketchUp window you have open. No Python or Node.js installation needed.

0What you need

  • Windows 10/11 and a recent Claude Desktop (download at claude.ai/download), signed in to your Claude account.
  • SketchUp 2017 or later (tested in real projects on SketchUp 2021 and 2023). Each SketchUp version must have been opened at least once before you install the plugin.
  • Unzip the zip file you downloaded (right-click → Extract All). The extracted folder contains 01_CLAUDE_EXTENSION\sketchup-mcp-__VERSION__.mcpb and 02_SKETCHUP_PLUGIN_BACKUP\su_mcp.rbz.
Project dataWhen you ask a question, Claude reads model information (object names, quantities, screenshots…) and sends it to Anthropic's Claude service for processing. Follow your firm's and your client's rules for confidential projects; while testing, work on a copy of the project file.

1Install the extension in Claude Desktop

  1. Open Claude Desktop → click your name/avatar → Settings (or Ctrl+,) → Extensions.
  2. Drag and drop sketchup-mcp-__VERSION__.mcpb into the Extensions window, or click Advanced settings → Install Extension… and pick the file.
  3. Review the SketchUp MCP extension details → click Install. Claude may warn that the extension is unsigned: this build is not code-signed, so only install a file you got from the project's official release, then click Install. The extension is enabled automatically after installation.
TipThe Microsoft Store version of Claude does not open a .mcpb file on double-click – install it through Settings as above. If you cannot see Extensions or the Install Extension button, your organization may have disabled this feature: contact your administrator. The extension's Configure page has a per-command Timeout (default 120 seconds) and the port (default 9876 – do not change it unless you are told to, because it must be changed in SketchUp at the same time).

2Install the SU MCP Bridge plugin in SketchUp

Quick way – let Claude install it

  1. Start a new chat in Claude Desktop and type:Install SU MCP Bridge in SketchUp
  2. Claude asks for permission to use the install_sketchup_bridge tool → click Allow. The result lists the SketchUp versions found on your computer (e.g. 2023: installed).
  3. Fully quit SketchUp and reopen it.
  4. Check: in SketchUp go to Extensions → SU MCP Bridge → Status; it must show “RUNNING on 127.0.0.1:9876”.

Backup way – install manually

SketchUp → Extensions → Extension Manager (SketchUp 2017–2020: Window → Extension Manager) → Install Extension → select 02_SKETCHUP_PLUGIN_BACKUP\su_mcp.rbz → confirm → restart SketchUp.

If the plugin does not run / SketchUp says the extension is unverifiedThis plugin is not digitally signed. In Extension Manager → the gear icon (Extension Loading Policy), choose Approve Unidentified Extensions or Unrestricted (not Identified Extensions Only) – as allowed by your IT policy.

3First try (read-only, safe)

Open a copy of a project file in SketchUp, then ask Claude, one at a time:

Ping SketchUp What is in this model? Summarize the tags, materials and components. Take an iso screenshot so I can see it.

ping tells you which model Claude is controlling and the plugin version; if there is a warning line, the plugin is outdated – see section 6.

4Working safely

  • Save a copy before every working session with Claude.
  • Every change Claude makes to the model is one Undo step (Ctrl+Z), named “MCP: …” in the Edit menu.
  • Keep Claude in ask-for-permission mode. Do not choose “Always allow” for: run_ruby, delete_entities, undo, save_model, open_model, new_model, export_file, export_png (the two export commands can overwrite files).
  • run_ruby runs any Ruby code inside SketchUp. If you cannot read and understand the code Claude proposes, deny it and ask Claude to use the built-in tools instead.
  • Claude only controls the first SketchUp window you open (the one holding port 9876). A second window you open is not connected.
  • A takeoff on a large model or a heavy run_ruby command can freeze SketchUp for seconds to minutes – please wait. If it stays frozen for too long after a run_ruby command (possibly an infinite loop), close SketchUp with Task Manager; unsaved changes will be lost.
  • The connection only listens on your own computer (127.0.0.1); other machines on the network cannot reach it.

5Example prompts

Read & summarize

“List the components and their counts, sorted from most to least.”
“Count the D1 doors and the windows in the model.”

Quantity takeoff

“Run a takeoff by tag and make a table of area in m² and volume in m³.”
“Only the current selection, grouped by material.”
Area is the total of all faces (a solid includes its top, bottom and side faces) – for floor area, say “top faces only”.

Modelling

“Create a 120 mm thick slab from the points (0,0), (6000,0), (6000,4000), (0,4000).”
“Move the selected objects up 300 mm.”

Materials & tags

“Assign the tag Walls to the selected objects.”
“Change the selected material to Tile 600x600 with color #D9D3C9.”

Export & views

“Take a top-view screenshot so I can check.” (your own view is kept)
“Export a 1920x1080 iso PNG to the Desktop, named perspective.png.”

Tips

State the units (mm). After each step, ask Claude to “take a screenshot to check”. If something is wrong, say “undo the last step”.

See the full list in SAMPLE_PROMPTS_EN.txt.

6Troubleshooting

Message (verbatim)CauseWhat to do
Cannot connect to SketchUp at 127.0.0.1:9876SketchUp is not open, or the plugin is not installed or is stopped.Open SketchUp; check Extensions → SU MCP Bridge → Status; if that menu is missing, repeat step 2.
SketchUp did not respond within 120s … MAY HAVE ALREADY RUNA model-editing command is taking a long time (large model) – it may already have finished.Do not ask Claude to redo it right away. Check the model; if something was duplicated, press Ctrl+Z. Increase the Timeout in Configure.
SketchUp did not respond within 120s … This command does not modify the model and can be retriedA read command (e.g. a takeoff on a large model) has not finished yet.Increase the Timeout in Configure first, wait until SketchUp is no longer busy, then ask again.
Unsupported command, or ping shows a warning lineThe plugin in SketchUp is older than the Claude extension.Type “Install SU MCP Bridge in SketchUp”, then fully quit and reopen SketchUp.
Status shows Port 9876 is used by another SketchUp windowTwo SketchUp windows are open.Close the other window, then click Extensions → SU MCP Bridge → Start server.
Status shows Windows does not allow port 9876The port is in a range reserved by Windows/Hyper-V.Extensions → SU MCP Bridge → Change port..., fully quit and reopen SketchUp, then set the same port in Claude: Settings → Extensions → SketchUp MCP → Configure.
run_ruby must not call exit/abortClaude's Ruby code called exit.The changes were rolled back. Ask Claude to rewrite the code without exit.
Claude does not see the SketchUp toolsThe extension is disabled.Claude → Settings → Extensions → SketchUp MCP → enable it; start a new chat.
Every SketchUp tool appears twiceAnother SketchUp MCP server (for example an older "sketchup" Python setup) is still configured in claude_desktop_config.json.Remove that entry (Settings → Developer → Edit Config), then restart Claude.

7Update & uninstall

  • Update: install the new .mcpb file over the old one (your settings are kept), then type “Install SU MCP Bridge in SketchUp” and restart SketchUp. Always update both parts, then type “Ping SketchUp” – if there is no warning line, you are done.
  • Uninstall: Claude → Settings → Extensions → SketchUp MCP → Uninstall. In SketchUp: Extension Manager → SU MCP Bridge → Uninstall (or delete su_mcp.rb and the su_mcp folder in %APPDATA%\SketchUp\SketchUp 20xx\SketchUp\Plugins).

8Report a problem / feedback

Open an issue on the project GitHub repository and include:

  1. The result of “Ping SketchUp” (SketchUp, plugin and extension versions).
  2. The log file: SketchUp → Extensions → SU MCP Bridge → Open log file (it records command names, times and errors – no geometry or code – but error messages may contain file or object names: review it and remove anything confidential before posting).
  3. A screenshot of the error message and the prompt you gave Claude.
