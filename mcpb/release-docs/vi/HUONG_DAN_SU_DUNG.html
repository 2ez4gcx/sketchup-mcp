SketchUp MCP – Cho Claude làm việc trực tiếp trong SketchUp

Hỏi Claude bằng tiếng Việt để đọc mô hình, bóc khối lượng, dựng hình, gán vật liệu/tag, chụp ảnh và xuất file — ngay trên SketchUp đang mở. Không cần cài Python hay Node.js.

0Cần có gì

  • Windows 10/11 và Claude Desktop bản mới (tải tại claude.ai/download), đã đăng nhập bằng tài khoản Claude của bạn.
  • SketchUp 2017 trở lên (đã chạy thử thực tế trên SketchUp 2021 và 2023). Mỗi bản SketchUp phải được mở ít nhất 1 lần trước khi cài plugin.
  • Giải nén file zip nhận được (chuột phải → Extract All). Trong thư mục giải nén có 01_CLAUDE_EXTENSION\sketchup-mcp-__VERSION__.mcpb (cài vào Claude) và 02_SKETCHUP_PLUGIN_BACKUP\su_mcp.rbz (dự phòng cho SketchUp).
Dữ liệu dự ánKhi bạn hỏi, Claude sẽ đọc thông tin mô hình (tên đối tượng, khối lượng, ảnh chụp…) và gửi lên dịch vụ Claude của Anthropic để xử lý. Hãy tuân thủ quy định của công ty với dự án có cam kết bảo mật; khi thử nghiệm nên dùng bản sao của file dự án.

1Cài extension vào Claude Desktop

  1. Mở Claude Desktop → bấm tên/ảnh đại diện của bạn → Settings (hoặc Ctrl+,) → mục Extensions.
  2. Kéo thả file sketchup-mcp-__VERSION__.mcpb vào cửa sổ Extensions, hoặc bấm Advanced settings → Install Extension… rồi chọn file.
  3. Xem thông tin extension SketchUp MCP → bấm Install. Claude có thể báo extension chưa được ký (unsigned) — bản này chưa ký số, chỉ cài file lấy từ nguồn phát hành chính thức của dự án, rồi vẫn bấm cài. Extension tự bật sau khi cài.
MẹoBản Claude cài từ Microsoft Store không mở được khi nhấp đúp file .mcpb — hãy cài qua Settings như trên. Nếu không thấy mục Extensions hoặc nút Install Extension, tổ chức có thể đã chặn tính năng này: liên hệ người phụ trách. Mục Configure của extension có thời gian chờ (Timeout) mỗi lệnh (mặc định 120 giây) và cổng (mặc định 9876 — không đổi trừ khi được hướng dẫn, vì phải đổi đồng thời trong SketchUp).

2Cài plugin SU MCP Bridge vào SketchUp

Cách nhanh — nhờ Claude cài

  1. Mở một cuộc chat mới trong Claude Desktop và gõ:Cài SU MCP Bridge vào SketchUp
  2. Claude sẽ xin phép dùng công cụ install_sketchup_bridge → bấm Allow. Kết quả liệt kê các bản SketchUp đã cài (vd 2023: installed).
  3. Thoát hẳn SketchUp rồi mở lại.
  4. Kiểm tra: trong SketchUp vào Extensions → SU MCP Bridge → Status, phải thấy “RUNNING on 127.0.0.1:9876”.

Cách dự phòng — cài tay

SketchUp → Extensions → Extension Manager (SketchUp 2017–2020: Window → Extension Manager) → Install Extension → chọn 02_SKETCHUP_PLUGIN_BACKUP\su_mcp.rbz → đồng ý → khởi động lại SketchUp.

Nếu plugin không chạy / SketchUp báo extension chưa xác minhPlugin này chưa được ký số. Trong Extension Manager → biểu tượng bánh răng (Extension Loading Policy) phải chọn Approve Unidentified Extensions hoặc Unrestricted (không chọn Identified Extensions Only) — theo quy định IT của công ty.

3Thử lần đầu (chỉ đọc, an toàn)

Mở một bản sao của file dự án trong SketchUp, rồi lần lượt hỏi Claude:

Ping SketchUp Mô hình này có gì? Thống kê tag, vật liệu và component. Chụp ảnh góc iso cho tôi xem.

ping cho biết Claude đang điều khiển mô hình nào và phiên bản plugin; nếu có dòng warning là plugin cũ — xem mục 6.

4Dùng an toàn

  • Lưu bản sao trước mỗi buổi làm việc với Claude.
  • Mỗi lần Claude sửa mô hình là một bước Undo (Ctrl+Z), tên bắt đầu bằng “MCP: …” trong menu Edit.
  • Giữ chế độ hỏi xin phép. Không chọn “Always allow” cho: run_ruby, delete_entities, undo, save_model, open_model, new_model, export_file, export_png (hai lệnh xuất có thể ghi đè file).
  • run_ruby chạy code Ruby bất kỳ trong SketchUp. Nếu không đọc hiểu được đoạn code Claude đề xuất, hãy từ chối và yêu cầu Claude dùng các công cụ có sẵn.
  • Claude chỉ điều khiển cửa sổ SketchUp mở đầu tiên (giữ cổng 9876). Mở thêm cửa sổ thứ hai thì cửa sổ đó không kết nối.
  • Bóc khối lượng mô hình lớn hoặc lệnh run_ruby nặng có thể làm SketchUp đứng vài giây đến vài phút — hãy chờ. Nếu đứng quá lâu sau một lệnh run_ruby (có thể do vòng lặp vô hạn), đóng SketchUp bằng Task Manager; thay đổi chưa lưu sẽ mất.
  • Kết nối chỉ nghe trong máy (127.0.0.1), máy khác trong mạng không truy cập được.

5Ví dụ câu lệnh

Đọc & thống kê

“Liệt kê các component và số lượng, sắp xếp giảm dần.”
“Đếm số cửa D1 và cửa sổ trong mô hình.”

Bóc khối lượng

“Bóc khối lượng theo tag, lập bảng diện tích m² và thể tích m³.”
“Chỉ tính phần đang chọn, gom theo vật liệu.”
Diện tích là tổng mọi mặt (khối đặc gồm mặt trên, dưới, cạnh) — muốn diện tích sàn hãy nói rõ “chỉ tính mặt trên”.

Dựng hình

“Tạo sàn dày 120 mm từ các điểm (0,0), (6000,0), (6000,4000), (0,4000).”
“Dời các đối tượng đang chọn lên 300 mm.”

Vật liệu & tag

“Gán tag Tường cho các đối tượng đang chọn.”
“Đổi vật liệu đang chọn sang Gạch 600x600 màu #D9D3C9.”

Xuất & góc nhìn

“Chụp ảnh góc trên cho tôi kiểm tra.” (góc nhìn của bạn được giữ nguyên)
“Xuất ảnh PNG 1920x1080 góc iso ra Desktop, tên phoi_canh.png.”

Mẹo

Nói rõ đơn vị (mm). Sau mỗi bước, nhờ Claude “chụp ảnh kiểm tra”. Sai thì bảo “undo bước vừa rồi”.

Xem thêm danh sách đầy đủ trong CAU_LENH_MAU.txt.

7Cập nhật & gỡ cài đặt

  • Cập nhật: cài file .mcpb mới đè lên (thiết lập được giữ), rồi gõ “Cài SU MCP Bridge vào SketchUp” và khởi động lại SketchUp. Luôn cập nhật cả hai phần, sau đó gõ “Ping SketchUp” — không có dòng warning là xong.
  • Gỡ: Claude → Settings → Extensions → SketchUp MCP → Uninstall. Trong SketchUp: Extension Manager → SU MCP Bridge → Uninstall (hoặc xóa su_mcp.rb và thư mục su_mcp trong %APPDATA%\SketchUp\SketchUp 20xx\SketchUp\Plugins).

8Báo lỗi / góp ý

Mở một issue trên repository GitHub của dự án (hoặc báo cho người hỗ trợ trong tổ chức của bạn), kèm:

  1. Kết quả lệnh “Ping SketchUp” (phiên bản SketchUp, plugin, extension).
  2. File log: SketchUp → Extensions → SU MCP Bridge → Open log file (ghi tên lệnh, thời gian, lỗi; không ghi hình học hay code — nhưng thông báo lỗi có thể có tên file/đối tượng, hãy xem lại trước khi gửi).
  3. Ảnh chụp màn hình thông báo lỗi và câu bạn đã hỏi Claude.
